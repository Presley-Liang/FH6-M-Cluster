# v4 科幻配色与平滑动画补充

2026-09-09。用户最新要求优先于 v4 旧色值；保留宝马双弧固定壳与四页架构。

最新六张实拍参考优先：见 [P3V_REFERENCE_REBUILD.md](P3V_REFERENCE_REBUILD.md)。蓝色漫游使用冷蓝薄光带，Race使用暗红底与红色累计带、银白前沿；不再仅靠原抽象双弧改色。下列色值作为方向而非像素级固定值。

## 配色

深空背景 #030609，石墨仪表层 #0A1119，主文字 #EDF7FF，次文字 #94A9BD。
漫游：离子蓝 #3298FF，局部冰青 #67DDFF，暗部 #102741。
比赛：等离子红 #FF4058，局部珊瑚光 #FF795B，暗部 #32121B。
科幻感来自精细发光边缘、分层透明面、低亮刻度和受控局部辉光；中央信息保持清晰，不用满屏霓虹或大面积模糊。
胎温、刹车、录制与异常颜色保持语义，不随模式变蓝。黄色→橙色→红色高转灯效独立于蓝红主题。

## 平滑标准

### 整套仪表点火 / 唤醒（2026-09-09新方案覆盖旧扫表）

旧“指针归零→满量程扫表”方案作废。新方案总时长约850–1200ms：短暂收光、两侧弧线按当前车辆量程唤醒、当前模式性能脉冲、车辆身份/RPM量程/BOOST锁定，最后平滑接回最新实时值。弧线可以做装饰性量程唤醒，但数字速度/RPM/挡位不得显示伪造扫表数据。首次稳定连接、AUTO模式确认、可靠换车及可选长断流恢复触发；500–1000ms内的多个原因合并一次，不排队补播。期间实时store、SSE、Session、MAP与Replay持续工作。reduced-motion保留状态/颜色，取消明显弧线扫动与位移。此为新P10实现项。

- 固定仪表节点始终复用。指针 rAF 按 dt 指数平滑，初值时间常数60–90ms；数字独立更新，不能被400ms主题过渡拖慢。
- 中央切页260–300ms，transform/opacity，曲线 cubic-bezier(.22,1,.36,1)。新目标接管当前可见位置，不先复位再播放，不累积动画队列。
- 主题实际颜色属性400ms过渡；Race灯条展开320ms、漫游顶框溢光交叉淡化320ms。遥测不停，灯光透明度连续跟随ratio。
- blur半径和巨大box-shadow不逐帧变更；预渲染辉光层只调opacity。禁止transition:all。
- 高转提示使用独立时钟，默认局部2Hz脉冲；不全屏闪。reduced-motion改稳定高亮。
- stale、换车、无有效engineMaxRpm时灯效安全熄灭；0.75/0.90/0.97阈值使用约0.015回差。
- 键盘左右仅在非输入控件/非地图键盘交互时切页；不可见页inert，焦点留在可见页。

## 验收

60Hz目标设备下记录60秒动画帧时间，目标p95≤20ms、p99≤34ms，连续快速切页20次无复位跳变、无长队列、无固定壳位移；不预先宣称已达到。120Hz屏按实际设备另测。地图加载与灯效同时开启时复测，地图性能退化只降低地图绘制频率，不降低基础仪表刷新。

## 数据与回放解释

324-byte parser未提供水温，固定小表应隐藏该读数或显示“不提供”，不能用胎温代水温。MAP常驻指实例和状态持续存在，不要求DRIVE页面重复显示地图。默认实时固定仪表与顶部灯效始终使用live store；RPY内回放使用replay store，避免只换灯效而速度仍是真实值。若未来允许全壳回放，必须显式标注REPLAY并同时切换所有显示选择器。
