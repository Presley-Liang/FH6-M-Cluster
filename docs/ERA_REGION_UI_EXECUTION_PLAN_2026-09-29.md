# 年代 × 地区仪表：当前实施计划

更新：2026-10-02。当前状态见[进度表](../PROGRESS.md)；33 个主题的视觉基准与去重约束见[设计台账](ERA_REGION_33_DESIGN_EXPECTATIONS.md)。

## 当前基线

- 11 个年代 × 3 个地区，共 33 个主题入口。
- 22 套已接入独立主画面，11 个编号仍使用共享仪表壳；主题入口和车辆卡已覆盖不等于独立仪表完成。
- 原 `2015–2019｜欧系` 是既有基准，保留其仪表画面和 Race／Free 动画。
- 新主题只呈现各自 Race／Free 的必要驾驶数据；两种模式是主题覆盖层，不复制完整皮肤。手动调试时可选择主题和模式。
- 换车固定为：旧仪表退场 → 全黑 → 一张融合品牌、车型和参数的卡片 → 新表构建 → 扫表 → 平滑接管最新遥测。没有单独车标轮次或 ENGINE／TELEMETRY／DISPLAY 自检。
- EV 是动力数据与布局覆盖。遥测没有可靠来源的 SOC、REGEN 等字段不显示为真实读数；动画运行时 Store、Session 和遥测持续更新。

新增 XT／Prius 年代日系仪表仅记为开发态接入，原厂图片核对与视觉验收待完成；[本轮来源与预览](JAPAN_XT_PRIUS_REFERENCE_AND_IMPLEMENTATION_2026-10-02.md)。

## 执行顺序

### 1. 先集中修复已审查的旧主题

问题按[审查报告](ERA_REGION_COMPLETED_THEMES_LAYOUT_AUDIT_2026-09-30.md)编号逐项处理。先修速度量程与扫表回落、关机期间画面闪回、重复缓动和扫表／实时值优先级；再处理名称准确性、窄窗可读字号、长圈时和重复信息。每项修复后保留边界检查，不能将代码审查或模拟预览称为真实驾驶验收。

## 每套交付门槛

1. 对照遥测字段矩阵列出真实可用数据；缺失字段隐藏或降级，不推测 SOC、REGEN、油温等值。
2. 复用公共数据绑定和状态机，主题视觉独立；分别核对 Race／Free 内容、颜色和动态切换。
3. 检查车辆卡、关机、构建、年代化扫表、实时值接管，以及连续换车和切模式时序。
4. 检查指针中心、刻度量程与扫表终点；在约 375px、469px、1440px 检查框体、数字、单位、按钮及长读数。
5. 分开记录自动检查、模拟预览、真实 FH6 驾驶、EV 现场与用户验收状态。

真实 FH6 持续驾驶、真实 EV 数据、持续帧率和用户视觉验收尚未完成；这些状态不由自动检查通过替代。
