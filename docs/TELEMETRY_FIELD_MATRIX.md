# FH6 遥测字段矩阵

本矩阵按仓库 `src/parser.js` 的 FH6 324-byte UDP 布局和 `public/js/telemetry-selectors.js` 的展示投影整理。解析器接受至少 323 字节；包最后一个字节是 padding。以下字段是在结构上固定存在的字段，**不代表每个场景、车型或时刻都有有效读数**。

## 更新与可用性约定

- 每收到一个长度有效的游戏 UDP 包，解析器便读取一帧字段；本项目没有保证固定包频率，也不应把频率写成固定 Hz。
- 结构存在性：字段有固定的包偏移并会被解析。值有效性：还需按有限数、合理范围、当前模式和车型能力判断；零可能是真实读数，也可能是静止/重置/游戏提供的默认值，不能一律当缺失或有效。
- 数据缺项可表现为无效数、占位值或车型/模式不支持；解析器没有统一的每字段有效位图。消费者需要保留 `null` / `unknown` / stale 状态，不可从一个数值猜出电动车、电量、冷却液温度或磨损。
- 角点后缀 `Fl/Fr/Rl/Rr` 表示左前/右前/左后/右后。此包布局本身不区分现实车辆的部件是否存在或传感器能力。
- 更新频率列中的“逐包”指收到有效 UDP 包时，不表示固定帧率或每秒保证更新次数。

## 解析字段

| 字段（角点组按后缀展开） | 含义 | 单位/编码 | 更新频率 | 结构存在 / 值有效性及可能缺项 | 支持的视觉元素 |
|---|---|---|---|---|---|
| `isRaceOn` | 游戏是否处于竞赛状态标志 | bool（由 s32 非零转换） | 逐包 | 结构存在；游戏菜单/会话切换时会变化，不能单独判定 Race/Free UI 模式 | 状态提示、活动状态判断 |
| `timestampMs` | 游戏遥测时间戳 | ms（u32） | 逐包 | 结构存在；游戏暂停/重置及计数回绕需由消费者处理 | 新鲜度、时间轴 |
| `engineMaxRpm`, `engineIdleRpm`, `currentEngineRpm` | 发动机最大、怠速、当前转速 | rpm | 逐包 | 结构存在；EV 可能没有有意义的发动机转速；换车/非驾驶画面可能为零或占位值 | RPM 表、红线比例、换挡灯；EV 必须走动力覆盖 |
| `accelX/Y/Z` | 加速度三轴 | m/s²；选择器换算为 g | 逐包 | 结构存在；静止时接近零是真实值；方向轴应以游戏坐标约定验证 | G 值 / G 轨迹 |
| `velX/Y/Z` | 速度三轴 | m/s | 逐包 | 结构存在；部分 UI 仅使用 `speedMs`，可用于运动方向/速度派生 | 速度/运动提示 |
| `angularVelocityX/Y/Z` | 角速度三轴 | rad/s | 逐包 | 结构存在；坐标语义应以游戏坐标系为准 | 旋转/姿态辅助显示 |
| `yaw`, `pitch`, `roll` | 航向、俯仰、横滚 | rad；选择器输出角度 | 逐包 | 结构存在；地图/姿态用途需校准轴向，不能当绝对地理朝向 | 车身姿态、地图朝向 |
| `suspensionFl/Fr/Rl/Rr` | 四轮归一化悬挂行程 | 归一化比例（协议标称） | 逐包 | 结构存在；比例的车型映射和有效范围未做逐车校准 | 四轮悬挂柱 |
| `tireSlipRatioFl/Fr/Rl/Rr` | 四轮纵向滑移率 | 无量纲比值 | 逐包 | 结构存在；数值范围随轮胎和游戏物理变化 | 四轮滑移状态 |
| `wheelRotationSpeedFl/Fr/Rl/Rr` | 四轮旋转速度 | rad/s | 逐包 | 结构存在；停车/空转是有效状态，不能由零推断字段缺失 | 车轮转速/打滑提示 |
| `wheelOnRumbleStripFl/Fr/Rl/Rr` | 四轮是否在路肩/震动带标记 | s32 标志值 | 逐包 | 结构存在；按标志值解释；游戏不在驾驶状态时可能无场景意义 | 路肩提示/轮胎状态 |
| `wheelInPuddleFl/Fr/Rl/Rr` | 四轮积水深度 | 0–1 比例（协议标称） | 逐包 | 结构存在；干燥路面为零是有效读数 | 积水/路况提示 |
| `surfaceRumbleFl/Fr/Rl/Rr` | 四轮路面震动量（控制器反馈量） | 无量纲 raw 浮点值 | 逐包 | 结构存在；跨车型视觉阈值未校准 | 路面反馈强度提示 |
| `tireSlipAngleFl/Fr/Rl/Rr` | 四轮侧偏角 | rad | 逐包 | 结构存在；小值可为有效；物理解释受游戏模型影响 | 四轮侧偏提示 |
| `tireCombinedSlipFl/Fr/Rl/Rr` | 四轮综合滑移 | 无量纲/游戏组合量 | 逐包 | 结构存在；本项目未建立跨车型阈值 | 综合滑移指示 |
| `suspensionTravelMetersFl/Fr/Rl/Rr` | 四轮悬挂行程 | m | 逐包 | 结构存在；轮端可动范围、车辆类型和游戏重置会影响读数 | 四轮悬挂行程指示 |
| `carOrdinal`, `carClass`, `carPi`, `drivetrainType`, `numCylinders` | 车辆 ordinal、性能级别、PI、驱动形式枚举、气缸数 | ordinal / 枚举 / PI 分值 / 气缸计数 | 逐包 | 结构存在；车型元数据目录未覆盖时 ordinal 仍可用但名称未知；EV 的气缸数为零/无意义不等于缺包 | 车型身份、PI、FWD/RWD/AWD 标签、资料卡 |
| `carGroup` | FH6 车辆分组字段 | u32 原始枚举 | 逐包 | 结构存在；本项目没有经验证的分类字典，保持 raw/unknown | 暂无可靠视觉映射 |
| `smashableVelDiff`, `smashableMass` | FH6 可破坏物碰撞相关字段 | raw 浮点数；本项目未核定单位 | 逐包 | 结构存在；无碰撞之外的车型有效性保证，不是车辆碰撞安全或稳定性传感器 | 目前无正式仪表视觉用途 |
| `positionX/Y/Z` | 游戏世界坐标 | 游戏世界单位；项目未确认米制 | 逐包 | 结构存在；菜单、传送、赛道重置会改变坐标；不是经纬度 | 地图点位/轨迹 |
| `speedMs`, `speedKmh`（后者由前者派生） | 车辆速度 | m/s；派生 km/h | 逐包 | `speedMs` 结构存在；倒车/静止为有效状态，显示单位需明确 | 速度表、地图速度 |
| `power` | 发动机/驱动功率字段 | W；选择器换算为 kW | 逐包 | 结构存在；车型/工况可给零或非典型值；不能由正功率认定 EV | 功率条/数字 |
| `torque` | 扭矩字段 | Nm（项目契约） | 逐包 | 结构存在；车型和转速影响有效范围 | 扭矩数字 |
| `tireTempFl/Fr/Rl/Rr` | 四轮胎温 | °C（解析时由华氏换算） | 逐包 | 结构存在；非驾驶/换车时可能占位；未建立逐车型校准或无效范围表 | 四轮温度点/热区 |
| `boost` / `boostRaw` | 增压原始值 | raw；本项目未证实物理单位 | 逐包 | 结构存在；非涡轮/不具增压能力车辆可能保持零或默认值；不能作为 EV/SOC 标记 | Boost raw 数字；学习出的能力状态需独立标注 |
| `fuel` / `fuelRaw` | 燃油原始字段 | raw；本项目未确认体积、比例或百分比单位 | 逐包 | 结构存在；EV/非驾驶状态及不同车型的值可能无意义；零可能是真实值 | 仅可标注 raw 的燃油指示；不得用来推断 EV 或 SOC |
| `distanceTraveled` | 当前游戏记录的行驶距离 | 游戏距离单位未由本项目核定 | 逐包 | 结构存在；计数可随会话/重置归零或回绕 | 行程/赛道进度 |
| `bestLap`, `lastLap`, `currentLap`, `currentRaceTime` | 最佳圈、上一圈、当前圈、当前比赛时间 | 秒 | 逐包 | 结构存在；自由漫游、未开赛、计时重置时可能为零/占位 | 圈速、计时、Delta 输入 |
| `lapNumber`, `racePosition` | 圈数与比赛排名 | 整数；lap u16、position u8 | 逐包 | 结构存在；非竞赛时排名/圈数不适用，需显示 unavailable 而不是有意义的 0 | 圈数、名次 |
| `throttle`, `brake`, `clutch`, `handbrake` | 四种驾驶输入 | u8 原始 0–255；选择器转百分比 | 逐包 | 结构存在；不同车辆没有离合踏板不等于缺字段；松开输入为 0 是有效值 | 踏板条/输入状态 |
| `gear` | 档位编码 | u8；项目映射 0=R、1–10=档位、11=N | 逐包 | 结构存在；EV/单速动力系统可能不具传统换挡语义；按确认的项目枚举映射显示 | 档位数字；EV 隐藏/替换换挡逻辑 |
| `steer` | 转向输入 | s8；选择器规范化为 -1..1 | 逐包 | 结构存在；中位 0 是有效值 | 转向条/方向提示 |
| `normalizedDrivingLine`, `normalizedAIBrakeDifference` | 游戏驾驶线与 AI 制动差异辅助值 | s8 原始归一化量 | 逐包 | 结构存在；AI/路线场景外未确认有效性和含义范围 | 可选驾驶辅助提示，默认 raw |

## 已有字段明确缺失的数据

- 没有电池 SOC、电量、能耗、再生制动功率或 EV 身份字段；EV 身份只能来自经过审查的车型元数据。不能把 `fuel` 或 `boost` 当作 SOC / EV 标记。
- 没有冷却液温度、机油温度、轮胎磨损、胎压字段；这些视觉项应隐藏、显示 unavailable，或明确作为非数据装饰。
- `carOrdinal` 可以连接本地名称目录，但游戏包本身不提供独立品牌、车型、年份、地区风格或动力类型字段。地区只用于主题展示：车型显式覆盖优先，其次使用带 `regionSource=brand-traditional-region-default` 和置信度的人工品牌传统地区默认；跨地区或不确定品牌保持 `unknown`。这不是遥测事实。动力类型来源不明时保持 `unknown`，只有目录名显式标记 `EV` 才自动套用 EV 覆盖，`fuel` / `boost` 不参与判断。
- 结构字段存在不代表车辆具备对应实体设备。例如所有包都有转速/档位/燃油字段，但 EV 或单速车上的这些值不能直接套用燃油车显示语义。
