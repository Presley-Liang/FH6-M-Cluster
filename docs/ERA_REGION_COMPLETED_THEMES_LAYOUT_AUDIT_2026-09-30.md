## 本轮修正与核对方式

- 在共享仪表宿主的 759px 以下布局中去掉固定最小宽度，让顶部控件分行，避免整个主题在窄窗中水平溢出。早期 911、S30、RX-8、R8、LFA、Taycan 的上述局部修正分别落在其主题样式或绑定文件中。
- 浏览器对 17 套主题检查约 375px、469px、1440px 的可视区域；对 Free／Race 文字框做边界与相互盖压检查，并查看代表性画面。车型卡逐套在 375px 检查卡片是否完全落在仪表区域、是否出现内部滚动。预览使用 `BRAND UNKNOWN / MODEL UNKNOWN` 等无遥测占位。
- 换车状态机现为旧表退场 → 全黑 → **完整车型卡** → 卡片退场 → 新表构建 → 扫表 → 最新值。完整卡在出现时同屏显示品牌、车型和参数；移除原先只显示品牌的 780ms 阶段及其样式。Race／Free 的原有切换流程不受此修改影响。
- 浏览器已实际看见完整卡的品牌、车型及参数同屏出现；剩余五套卡片（原欧系、Ford GT、Taycan、C8、全景投影）连同之前十二套均未超出 375px 仪表区域。完整顺序检查 **164/164 通过**，`git diff --check` 无补丁空白错误。

## 2026-09-30 · 本批三套与既有主题的还原、拟真审查

本轮使用当前模型，分别进行本批原厂参考对照与既有 16 套源码／资料审查；主线程负责修正与浏览器复核。下表是来源与构图落实程度，不是用户画面或真实 FH6 验收等级。

### 本批已经据审查修正

- `2020–2024｜日系`：以 [Honda Civic Type R 2023 +R 原厂仪表](https://global.honda/content/dam/site/global-jp/news-new/cq_img/2022/07/dl/4220721_019H.jpg) 为参考。改为左端上扬、右端水平的连续转速尺，刻度在尺下，挡位进入下方凹口；下区圈速／驾驶参数／二维 G 分置。换挡灯按真实 RPM 从两侧向中心逐步点亮；窄窗速度字号修正。
- `2025 以后｜美系`：以 [Cadillac Escalade 官方座舱](https://www.cadillacarabia.com/sa-en/crossovers-suvs/2025-escalade) 为参考。驾驶核心靠左，速度旁增加带斜升段和数字刻度的转速尺，弱化绿色金属，改黑玻璃／细金属。55 英寸指整体显示系统，不能把整条解释成纯仪表。
- `2025 以后｜日系`：以 [GX550 Type 3 官方计器](https://manual.lexus.jp/gx/3056/cv/ja_JP/contents/vhch02se010402.php) 为参考。缩小中上速度与挡位，左右辅助小表、下方细状态区，减轻厚蓝框和满高分隔。
- `2025 以后｜欧系`：撤销右下角独立斜切辅助牌，将必要读数并入上方投影带右侧，下面保留连续仪表台曲面与接触阴影。根据 [BMW Panoramic iDrive 官方说明](https://www.press.bmwgroup.com/usa/article/detail/T0447356EN_US/new-bmw-panoramic-idrive-revolutionizes-vehicle-operation) 的投影小组件方向适配。

上述不是逐像素复制。FH6 的模式、圈时、轮胎温度、功率和油门替换没有可靠源的油温／油压／电压等栏目。GX 的左罗盘改明确标注 VEHICLE YAW 的真实车体角度，右 Boost 弧改真实转速／驱动输入；不制造导航、巡航、水温、SOC 或 REGEN。Free/Race 继续是主题上的模式覆盖层。
