# FH6 M Telemetry 简短使用教程

## 运行

1. 解压收到的 `FH6-Telemetry-Windows` 文件夹。
2. 双击 `启动仪表.bat`（推荐）；它会自动处理已运行实例和端口占用。
3. 也可以直接双击 `fh6-telemetry.exe`。
4. 浏览器打开 <http://localhost:3000>。

如果 exe 双击后立即关闭，也可以使用项目根目录的 `启动仪表-调试版.bat`；它会保留命令窗口并直接显示错误信息。

## 游戏设置

在 FH6 的 **设置 → HUD 和游戏玩法 → Telemetry** 中设置：

- **Data Out**：On
- **Data Out IP Address**：`127.0.0.1`（游戏和仪表在同一台电脑）
- **Data Out IP Port**：`20440`

回到驾驶状态后，仪表会自动接收速度、转速、挡位、踏板、G 值、胎温、位置、圈速等数据。

## 模式

- 进入正式比赛后自动切换为红色 Race，并自动记录 Session、圈轨迹和赛道识别。
- 退出比赛回到自由驾驶后自动切换为蓝色 Free Roam。
- MAP 页面显示离线地图、车辆位置和当前轨迹；已识别过的赛道会显示完整轮廓。
- DYN 页面显示车辆俯视图、四轮胎温和踏板柱状数据。

## 注意

- 程序运行时不要关闭黑色命令窗口（如果系统没有显示窗口则无需处理）。
- 关闭仪表可直接关闭程序；已保存的 Session 位于程序目录的 `sessions` 文件夹。
- 如果显示 NO TELEMETRY，先确认游戏中的 Data Out 已开启、端口为 `20440`，再让车辆实际行驶几秒。
