# P9-V DYN车辆状态舱规划

日期：2026-09-09

状态：开发态已完成（126/126自动化通过；1280×720合成数据红蓝模式手动检查通过；真实FH6标定归P11）。

## 目标

将当前DYN的可滚动工程参数列表改造成单屏驾驶视图。信息按车辆空间位置组织，不要求驾驶者逐行阅读；在1280×720及常见仪表窗口内禁止出现滚动条。

## 单屏结构

```text
┌──────────────── DYN / VEHICLE STATE ────────────────┐
│  FL 温度  Slip              FR 温度  Slip            │
│       ╲    ┌──────── 车辆俯视模型 ────────┐    ╱       │
│            │ 前后轴 / 驱动形式 / 受力光带 │            │
│       ╱    └──────────────────────────────┘    ╲       │
│  RL 温度  Slip              RR 温度  Slip            │
├──────────────────────────────────────────────────────┤
│ THROTTLE ███████░  BRAKE ███░░░░░                    │
│ CLUTCH   ██░░░░░░  HANDBRAKE ░░░░░░░░                │
└──────────────────────────────────────────────────────┘
```

## 上半部分：车辆俯视模型

- 中央使用代码绘制的简化车辆俯视轮廓，避免照片风格和外部车型素材依赖。
- 四个车轮必须固定对应FL/FR/RL/RR，读数贴近物理轮位，不能再排成普通四列卡片。
- 每轮首要显示胎温；第二信息默认显示combined slip，危险时以颜色和短标签突出。
- Slip危险阈值由绑定层调用方显式配置；在取得真实FH6样本前默认不启用危险判定。
- 悬挂travel作为轮边细环或短行程条，不再长期占用独立文字行；详细ratio/angle/meters留给调试或后续展开层。
- 中央车体只保留驱动形式和必要状态。G-force可用车体下方二维小光点表达；Pitch/Roll/Yaw不再作为三行常驻数字。
- 胎温、磨损或水温等协议没有提供的字段必须显示`— / NOT PROVIDED`，禁止估算。

## 下半部分：驾驶输入柱

- 油门、刹车、离合、手刹采用四根水平柱，组成2×2固定网格。
- 柱体显示0–100%与末端数值；油门使用青绿功能色、刹车红色、离合冷白/蓝灰、手刹琥珀色。
- 转向在上下区域之间使用一根以中心为零的双向细条，不和四根0–100%柱混用。
- 高频值只更新transform/scale与文本，不重建节点；使用rAF批量绘制并保持现有stale策略。

## 模式视觉

- Race沿用深黑、红色能量边和更强危险状态；Free Roam沿用蓝青轮廓和更柔和环境光。
- 温度、刹车、警告色属于功能色，不应被红蓝主题变量覆盖。
- P9-V先完成静态层级与实时绑定；轮胎热晕、悬挂脉冲、输入柱回弹等动画统一留到P10协调器接管。

## 数据保留与裁剪

- parser和telemetry selector中的完整轮胎、Slip、悬挂、姿态、输入字段全部保留。
- DYN主视图只显示驾驶关键摘要；被隐藏的工程字段仍存在于JSON、SSE、Session和测试中。
- 若后续需要全部原始字段，使用独立debug页面或检查器，不在DYN恢复滚动参数墙。

## 验收标准

1. 1280×720、1920×1080和当前仪表窗口均无纵向/横向滚动条。
2. FL/FR/RL/RR用带差异的合成数据验证，位置与parser轮序完全一致。
3. 四根输入柱在0、50%、100%及stale时显示正确，转向负值向左、正值向右。
4. 地图、固定仪表、Session与SSE不因DYN切页或更新中断。
5. DYN保持单一稳定DOM，红蓝模式切换和P10动画不触发布局跳动。
