## 更新后的验收门槛

1. 保留该年代、该地区的既有视觉方向和参考记录。未注明可靠来源的构图不得当成原厂史实；原厂逐型号拟真不再作为完成门槛。
2. 审查时把新主题与全部已完成主题的 Free、Race 和缩小到相同尺寸的轮廓图并排。主读数几何、速度／转速位置、辅助数据拓扑三项中，至少有一项**主结构**明显不同；材质、配色、字形与光效只是进一步区别，不能独自充数。若与最近的已完成主题仍易混淆，开工前换参考车或重画布局。
3. 共用换车和模式状态机的**阶段顺序**；每套在退场、构建、扫表的表盘动作可不同。模式标题必须在重亮和扫表前完全消失；换车时卡片先于新仪表构建。指针中心、扫表终点和实时值接管逐套核对。
4. 新主题只做 Race／Free 必要数据，不复制旧基准的 DRIVE／MAP／DYN／RPY 分页；保留 `2015–2019｜欧系` 原仪表和原模式动画。EV 是数据／布局覆盖，实际没有的 SOC、REGEN 等不画假读数。
5. 每个主题保留Free/Race构图、与最近似主题的区别、退场／构建／扫表关键帧及可用遥测字段；独立读数避免重复，数字与对应指针／进度条可以同时显示。预览通过与真实FH6驾驶验收分开记录，来源记录不再要求补做原厂拟真。
6. 每套完成前检查窄窗约 375px、侧边预览约 469px 和宽屏约 1440px 下的 Free／Race 框体、数字、单位、顶部控制及车型卡位置；覆盖扫表峰值、回落和长读数。存在裁切或重叠时，主题的布局验收保持未完成。

## 逐主题构图台账

### Race 战斗风设计与实施（2026-10-10）

用户取消“全部黑红”的硬限制，并允许Race改变格子大小、区域排布与切换动画。大纲按33套当前实际画面重列后，用户再次授权开始；本轮已实施逐主题配色、32套专属双向动作与必要的驾驶重点变化，原欧系完整动画保留。运行时状态及验证结果见当前进度。

#### 共同目标

- Free以速度、车辆状态和巡航为主；Race把转速／功率、挡位、换挡提示、圈速／Delta推到驾驶焦点。速度保持可读，驾驶关键告警不降亮。
- 明暗层级、区域面积和数据排序一起变化，整幅画面能辨认竞技状态。普通数字以清晰的冷白／中性灰／准确屏幕本色为主；不把每个字染成强调色。
- 每主题以一个主要竞技强调色配独立材质，不要求33种完全不同的颜色。危险／临界、油门／制动、领先／落后、真实再生保留语义，通过图标、区域及亮度区分。
- 车型卡与对应主题共享材质和色系；品牌融于卡片，不增加单独车标阶段或ENGINE自检。

配色、布局与专属动作见下方33套逐项表；不再使用按风格类别归纳的Race实施表。

#### Race竞技配色规范（2026-10-10重新核对）

用户要求撤掉琥珀等温暖强调色，整体更有竞技感。本轮重选的是实际颜色，不保留铜橙／赭橙／暖黄／奶油色／棕金色作为Race主视觉，也不把它们换一个名称继续使用。

- 面板以冷黑、炭灰、枪灰、蓝黑区分材质；机械浅色面与C4正显面改为中性冷白灰。银色和玻璃反光保持中性；Free原有木纹／象牙／黄铜等材质保留，Race不以大面积棕金色塑造怀旧气氛。
- 主数字与刻度优先冷白；主要参考为冷白#F4F7FA、暗面#070A0E、分区#151B23。最终以读数对比度与各主题实景为准。
- 每套只选一个主要竞技强调色：性能红#FF3045、电蓝#2F8FFF、电光青#45E0FF、荧光绿#7AFF35。用于动力轨迹、针、驾驶边线与局部照明，不能把所有数字与大面板都染亮。
- 主动力区最强，挡位大而清楚，比赛信息次强，装饰最弱。颜色依照当前区域分布和材质决定，33套无需强凑33个色相。
- 危险红、语义提示黄、领先／落后、制动／油门、真实再生继续是状态颜色。黄色仅作为真实提示，不铺成暖色运动主题；红色主题的告警须通过图标、位置与亮度区别普通强调。
- 顶部按钮、模式标题、车型卡、该套专属动作、重亮和扫表照明一起使用对应主题配色；旧模式退场期间仍保持旧色，在原交接点切入目标色。

#### 普通数据切换为竞技数据

| 区域 | Free | Race |
|---|---|---|
| 主读数 | 速度优先，转速／功率辅助 | 转速／功率与挡位优先，速度缩到仍清楚可读的次级区域 |
| 普通状态格 | 巡航／车辆状态、基本行驶信息 | 当前圈、有效Delta、最佳圈、当前圈数／排名；按主题选择，不全部塞满 |
| 辅助驾驶格 | 温和的动力／行驶状态 | 踏板输入、明确轴向的G值、有效四轮胎温、功率／扭矩；机械主题只挑少量重点，数字主题可以更密集 |
| 提示区 | 连接与基本状态 | 换挡预告、临界转速、新最佳圈等现有反馈；EV用真实功率重点替代传统RPM换挡语义 |

竞技内容根据真实可用数据选择，不能点击Race后凭空出现比赛计时。没有有效圈速／Delta／排名时明确显示未计时或隐藏对应区域；可改为有效动力、G值或输入数据，但标签、单位及布局必须同步切换。Boost只能使用准确标注的raw数据，不虚构压力单位；没有水温／油温／胎压／SOC等字段，不增加假值。地图只在确有用途的已有模块中保留，新的32套仍不复制DRIVE／MAP／DYN／RPY分类。

替换采用“旧内容收起 → 标签与数据来源同时交接 → 新格子展开”，不把旧数字套上新单位、不叠两份主读数。底层真实采集与记录持续更新，动画只负责显示。

具体当前结构修正：AA是一个中央速度筒，不是三枚主针表；S30三联宽屏在右、窄屏在上；LFA侧窗为左右各两个圆形数据窗；Panoramic当前辅助数据在右侧投影内，下台面保持完整。未来实施必须以这些实际结构为准。

允许Race适度重排、完整表舱移位、格子比例改变或数据换页，但不强迫每套伸缩。原欧系基准保留已认可动作。每套配色、普通数据到竞技数据的交接与逆向恢复均需一并落实，不能只实现表中的装饰效果。

#### 动画链设计与审核门槛

模式：旧模式有动作地收拢／熄灯 → 模式标识 → 标识完全退场 → 目标配色与布局展开／锁定 → 重亮 → 年代化扫表 → 最新实时值接管。

换车：旧仪表有动作地退出 → 全黑 → 融合品牌的车型卡 → 卡片退场 → 新仪表构建／布局锁定 → 点亮 → 扫表 → 最新实时值接管。

- 新布局运动嵌入既有构建／重亮窗口，不随意拉长整条启动链。目标配色在原模式交接点应用，旧仪表退场过程中保持旧颜色。
- 必须在扫表开始前完成表盘与数据格的最终定位；模式标题已完全不可见，不能存在暗淡余字。
- 表盘／刻度／指针使用同一整体变换和坐标系。针中心、半径、量程、SVG比例及数字终点逐套反解核对；不能只扩大表盘却留下旧针坐标。
- 不出现先显示实时RPM→突然归零→再扫表；接管直接落到当前最新值。真实动力缺失仍降级，EV为功率布局覆盖。
- 快速连点、Race／Free中途反切、换车打断和减少动画设置必须取消旧动画回调；新目标收敛到单个活动仪表，不残留旧格子／颜色。
- 布局变化不阻塞遥测、Store、Session；动画结束读取最新数据。新增动画只发生在切换期间，不添加常驻重光效。
- 实施后按每套Free→Race、Race→Free、换车及中途打断审查，并检查375／469／1440窗口、长读数、针坐标、扫表终点、断流与EV边界；本轮仅完成设计审查，没有跑新实现的动画检查。
