# Oxanium

Unmodified variable TrueType font downloaded from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/oxanium

Upstream filename: `Oxanium[wght].ttf`; local filename: `Oxanium-Variable.ttf`.
Copyright 2019 The Oxanium Project Authors. SIL Open Font License 1.1 is retained in `Oxanium-OFL.txt`.

Used locally for the cluster's squared display numerals and labels. No font CDN is required at runtime.
